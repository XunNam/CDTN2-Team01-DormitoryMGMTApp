# Mẫu bàn giao cho Bùi Thế Anh

```text
Task / role / người thực hiện / revision:
Trạng thái đề nghị:
Giai đoạn hiện tại / phạm vi phiên đã thực hiện:
Các giai đoạn và operation còn lại:
File kế hoạch / checkpoint / bước tiếp theo chính xác:
Operation đã triển khai (method/path/operationId):
Tóm tắt hành vi thực tế:
File được tạo/sửa và exported function chính:
Router đã nối ở đâu:
DTO/error/auth/schema/business rule được dùng:
Transaction và protocol khóa:
Dependency đã có / chưa có:
Lệnh kiểm tra đã chạy và kết quả thực tế:
Ca đúng/sai input/chưa login/sai role/khóa/ownership:
Ca retry/cạnh tranh/rollback:
Kiểm thử chưa chạy và lý do:
Test DB/tích hợp giao Anh (NOT_RUN_PENDING_OWNER): file, setup, lệnh và expected result:
Giới hạn/lỗi còn lại:
Ảnh hưởng UI/role khác/schema/seed:
Contract hoặc migration thay đổi (nếu có, kèm decision):
Hướng dẫn tái hiện bằng dữ liệu giả:
Điều kiện Anh cần kiểm tra trước merge:
Các thao tác Git người dùng tự thực hiện:
Xác nhận AI chưa tự commit/push/merge/tag/phát hành/triển khai.
```

Anh review contract và diff, chạy lại test cần thiết trên bản tích hợp rồi mới xác nhận DONE. Không chỉ dùng câu trả lời AI hoặc ảnh chụp HTTP 200 để xác nhận quyền, sức chứa và tiền đúng.
